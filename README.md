`Python` `TensorFlow` `MobileNetV2` `Computer Vision` `RAG`

- Integrated visual features with environmental variables, including temperature, humidity, and soil pH, achieving 97.65% classification accuracy.
- Currently developing a Retrieval-Augmented Generation (RAG) component to retrieve relevant plant disease knowledge and provide contextual, information-based responses.
- Exploring the integration of computer vision and LLM-based retrieval to create a more comprehensive plant disease assistance system.
